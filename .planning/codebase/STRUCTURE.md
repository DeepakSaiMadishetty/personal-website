## Directory Purposes

**src/:**
- Purpose: All source code for the React application
- Contains: React components, pages, CSS, assets
- Key files: `App.jsx`, `main.jsx`, `index.css`

**src/components/:**
- Purpose: Reusable UI components used across pages
- Contains: React components with corresponding CSS files
- Key files: `Card.jsx`, `Navbar.jsx`, `Footer.jsx`, `FloatingButton.jsx`, `CursorIcon.jsx`

**src/pages/:**
- Purpose: Page-level components that serve as route targets
- Contains: Full-page views for each route, each with CSS file
- Key files: `Home.jsx`, `About.jsx`, `Experience.jsx`, `Projects.jsx`, `Education.jsx`, `Skills.jsx`, `Contact.jsx`

**src/assets/:**
- Purpose: Media and image files used in application
- Contains: SVG files, images
- Key files: `react.svg`

**.github/workflows/:**
- Purpose: GitHub Actions CI/CD automation
- Contains: Workflow definitions for automated tasks
- Key files: `deploy.yml` - automated GitHub Pages deployment on push to development branch

**dist/:**
- Purpose: Build output directory (generated by Vite during build)
- Contains: Optimized production bundle with minified JS and CSS
- Key files: `assets/` subfolder with bundled JavaScript and CSS

## Key File Locations

**Entry Points:**
- `index.html`: HTML document that loads the React application
- `src/main.jsx`: JavaScript entry point that mounts React to DOM
- `src/App.jsx`: Root React component that defines routing structure

**Configuration:**
- `package.json`: NPM dependencies and build scripts
- `vite.config.js`: Vite build tool configuration (base path, React plugin)
- `eslint.config.js`: ESLint linting rules
- `.github/workflows/deploy.yml`: GitHub Pages deployment automation

**Core Logic:**
- `src/App.jsx`: Route definitions and application layout
- `src/components/Navbar.jsx`: Navigation with route links
- `src/pages/*.jsx`: Page content and layout

**Styling:**
- `src/index.css`: Global styles and CSS custom property tokens (colors, spacing, shadows)
- `src/App.css`: Root application component styles
- `src/components/*.css`: Component-scoped styles (one per component)
- `src/pages/*.css`: Page-scoped styles (one per page)

**Testing:**
- None present (no test files in codebase)

## Naming Conventions

**Files:**
- Components: PascalCase (e.g., `Card.jsx`, `Navbar.jsx`, `FloatingButton.jsx`)
- Pages: PascalCase (e.g., `Home.jsx`, `About.jsx`, `Contact.jsx`)
- Styles: Matching component name with .css extension (e.g., `Card.css`, `Navbar.css`)
- Entry points: Lowercase (main.jsx, index.html, index.css)

**Directories:**
- Lowercase plural for feature collections (src/components/, src/pages/, .github/workflows/)
- Descriptive, domain-specific names

**CSS Classes:**
- kebab-case for class names
- Pattern: `.component-name` for root, `.component-name--variant` for variants, `.component-name__element` for nested elements
- Examples: `.nav-link`, `.nav-link--active`, `.card`, `.floating-btn`, `.floating-btn--secondary`

**React Components:**
- Export as default (e.g., `export default Navbar`)
- Accept props object for flexibility
- No prop destructuring in function signature for optional props

**Variables:**
- camelCase for JavaScript variables
- CONSTANT_CASE for CSS custom properties (e.g., `--primary`, `--shadow-card`)

## Where to Add New Code

**New Feature (e.g., new portfolio section):**
- Primary code: Create new page file in `src/pages/NewSection.jsx`
- Styling: Create `src/pages/NewSection.css` with component-scoped styles
- Routing: Add Route in `src/App.jsx` and navigation item in `src/components/Navbar.jsx` navItems array
- Data: Store content as array/object within the page component (pattern used in Projects, Experience)

**New Component (reusable UI element):**
- Implementation: Create component file in `src/components/ComponentName.jsx`
- Styling: Create `src/components/ComponentName.css`
- Pattern: Use Framer Motion for animations, accept delay prop for stagger control in parent
- Export: Default export of component

**Utilities (shared helper functions):**
- Location: Consider creating `src/utils/` directory if needed
- Pattern: Not yet present in codebase - only create if multiple files need shared logic

**Animation Library (Framer Motion):**
- Location: Use throughout components via imports
- Pattern: Import `motion` and animation hooks from framer-motion
- Common patterns: `motion.div`, `useInView`, `motion.nav`, `motion.a`

**Styling:**
- Global tokens: Add CSS custom properties to `src/index.css` :root selector
- Component styles: Keep styles in component-scoped CSS files
- Do not use: CSS-in-JS libraries (not in dependencies)

## Special Directories

**dist/:**
- Purpose: Production build output directory
- Generated: Yes (created by `npm run build`)
- Committed: No (listed in .gitignore)
- Contains: Optimized JavaScript bundles, CSS, and assets for GitHub Pages deployment

**.github/workflows/:**
- Purpose: GitHub Actions workflow definitions
- Generated: No (manually committed)
- Committed: Yes
- Deployed: GitHub automatically runs these on push events

**node_modules/:**
- Purpose: Installed npm dependencies
- Generated: Yes (created by `npm install` / `npm ci`)
- Committed: No (listed in .gitignore)
- Lock file: `package-lock.json` ensures reproducible installs

**.git/:**
- Purpose: Git version control metadata
- Generated: Yes (created by `git init`)
- Committed: N/A (version control system)

**public/:**
- Purpose: Static assets served directly (not processed by build)
- Generated: No (manually committed)
- Committed: Yes
- Access: Served at root path during dev and production

## Import Paths

**Relative Imports (used throughout):**
- Pages import components: `import Card from '../components/Card'`
- Components import CSS: `import './Card.css'`
- Pages import CSS: `import './Home.css'`

**No Path Aliases:** The project does not use TypeScript path aliases or `jsconfig.json` path mapping

**External Imports:**
- React: `import { Component, hook } from 'react'`
- React Router: `import { Routes, Route, Link, NavLink } from 'react-router-dom'`
- Framer Motion: `import { motion, useInView } from 'framer-motion'`
- React Icons: `import { FaIcon } from 'react-icons/fa'`
